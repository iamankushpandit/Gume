# Case — ESP32-2432S028R

This board is one of the 2.8-inch family, and they share an outline, so the
case for it is the one in **[../E32R28T-1/](../E32R28T-1/)** — a complete
printed shell with a 20 mm speaker grille and four printed clips, no metal
hardware. There is nothing board-specific to print here.

That folder is named for the E32R28T-1 because that is the board Braino ships
against; it is not a claim that this one is different. The fit was checked by
the maintainer on the 2.8-inch boards to hand rather than on every variant, so
if yours does not fit, please
[open an issue](https://github.com/iamankushpandit/Gume/issues) — it would mean
the family is less uniform than the case's README says.
