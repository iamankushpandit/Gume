Try it before it ships.

These builds are not releases. Each one is here because somebody holding a board nobody else has offered to test it, and this is the quickest way to put it in their hands: plug the board in, press the button, and say what you saw in the issue it came from. A build stays here until it ships or is dropped.

Same flashing as the installer: desktop Chrome, Edge or Opera, over USB. The console will not offer to update from one of these, and it keeps its profiles and scores; to go back, install a release from the Install page.
