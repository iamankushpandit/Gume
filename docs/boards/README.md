# Supported boards

Five boards run Braino!, and every one of them has been flashed and run on
hardware. This folder has one page per board: how to recognise it, what has
been checked on it, where its facts came from, and -- generated from the
firmware itself -- every pin the firmware uses.

| Screen | Touch | USB | Battery | Board | Page |
|---|---|---|---|---|---|
| 4-inch | resistive | one USB-C | yes | E32R40T | [E32R40T](E32R40T.md) |
| 3.2-inch | resistive | one USB-C | yes | E32R32P | [E32R32P](E32R32P.md) |
| 2.8-inch | capacitive | one USB-C | yes | Freenove FNK0104B / LCDWIKI ES3C28P | [Freenove-FNK0104B](Freenove-FNK0104B.md) |
| 2.8-inch | resistive | one USB-C | yes | E32R28T-1 (LCDWIKI E32R28T) | [E32R28T-1](E32R28T-1.md) |
| 2.8-inch | resistive | USB-C **and** micro-USB | **no** -- run it from USB power | ESP32-2432S028, inverted panel | [ESP32-2432S028-inv](ESP32-2432S028-inv.md) |

The two 2.8-inch resistive boards look alike; the second USB socket is the
difference. A board that is not in this table is not supported: a mismatched
image gives a blank or wrongly coloured screen rather than an error.

## How these pages stay true

Board facts go stale in two ways, and each page is built against both.

- **The firmware changes.** The facts table, the GPIO table and the pin
  diagram on every page are generated by `tools/gen_board_docs.py` from the
  board's profile in `include/boards/` and its `[board_*]` section in
  `platformio.ini` -- the two files the firmware itself is built from. Edit a
  profile and re-run the tool; CI fails if a page has fallen behind
  (`--check`). Do not edit between the GENERATED markers by hand.
- **The sources move.** Vendor pages get rewritten, renamed and taken down.
  Every source is listed with the date it was last checked and, where the
  Wayback Machine has one, an archived copy. When a link dies, the archive is
  what is left; when a page changes, the date says how old our reading of it
  is.

## Why the pictures are our own

The vendor pages state no licence for their photos, drawings, schematics or 3D
models, so they are all-rights-reserved and this repository -- published under
the GPL -- does not copy them. Each page links to them instead. The pictures
here are ours: the generated pin diagram, the printable case's render where
there is one, and photos of the boards themselves.

**Adding a photo:** put it in `img/` as `<BOARD_NAME>-front.jpg` (or `-back`,
`-side`, ...), keep it under about 300 KB, and run
`python tools/gen_board_docs.py`. The page picks it up. Only photos you took
yourself -- the licence rule above applies to pictures of boards too.
